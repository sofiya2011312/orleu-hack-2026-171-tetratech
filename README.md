О проекте

QazaqTrip — это интерактивный туристический веб-сервис, созданный для знакомства с достопримечательностями Казахстана и планирования путешествий по стране. Он помогает туристам находить интересные места, изучать информацию о них и ориентироваться на интерактивной карте. Проект направлен на развитие внутреннего туризма и делает путешествия по Казахстану более доступными и удобными.

Демо

- Сайт: https://arina0283.github.io/Trip/#map-section
- Презентация: https://canva.link/dus03sitzoonryk
- Видео: https://drive.google.com/file/d/13GW4h_UUvQHzWRi2Czalxs2cW22kcJCV/view?usp=drivesdk

Стек

- HTML5 — структура веб-сайта.
- CSS3 — оформление, дизайн и адаптивная вёрстка.
- JavaScript (Vanilla JS) — интерактивность, поиск достопримечательностей, построение маршрутов и планирование путешествий.
- Leaflet.js 1.9.4 — интерактивные карты.
- OpenStreetMap — картографические данные.
- Overpass API — получение данных о достопримечательностях, кафе и общественных туалетах.
- OSRM API — построение автомобильных маршрутов.
- Open-Meteo API — получение информации о погоде.
- Wikimedia Commons API — поиск изображений достопримечательностей.
- Google Fonts — типографика (DM Sans, Playfair Display).

База данных и собственная серверная часть не используются.

Как запустить

1. Склонировать репозиторий:
   
   git clone https://github.com/sofiya2011312/orleu-hack-2026-171-tetratech.git

2. Перейти в папку проекта:
   
   cd orleu-hack-2026-171-tetratech

3. Открыть папку проекта в Visual Studio Code.

4. Запустить файл "index.html" через расширение Live Server.

5. Сайт откроется в браузере.

Дополнительная установка зависимостей и настройка переменных окружения не требуются. Для работы динамических функций необходимо подключение к интернету.

Переменные окружения

Проект не требует дополнительных переменных окружения и API-ключей для запуска. Используемые внешние API не требуют указания персональных ключей доступа в проекте.
